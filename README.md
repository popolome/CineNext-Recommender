# CineNext-Recommender
Moving beyond generative AI to explore deterministic recommendation engines using Cosine Similarity and Vectorization.

## Try my Recommender App here:
https://cinenext-recommender.streamlit.app/

<br>

Search for Korean movies and the AI will search using Vectorization using ChromeDB on the most similar meaning to the word 'Korean'.
